Interact with the sliders to modify vertical and horizontal velocity, aswell as Gravity.

Press start to turn on the simulation, some UI elements become inaccesible while the simulation has started.

Press "Trajectory" to illustrate the current path of the object.

You can draw obstacles by dragging with your mouse around the screen.

You can drag the object by hovering over it, clicking and dragging around the screen.

If you mantain pressed shift while dragging the object you will be able to throw it!

Modify the forces on the top right to see how the object react to them!
